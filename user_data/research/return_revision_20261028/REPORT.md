# 報酬率改善實驗（2026-10-28）

固定每筆 0.5% 預算風險、最高 2 倍槓桿，測試只做多及 ADX(14) ≥ 25。
2023 排序候選；2024 為已知開發資料確認。兩者都不是全新樣本外結果。
2025／2026 未用於本次比較、挑選或調參。

資格：至少 10 筆、淨年化為正且高於基準，時價回撤 ≤ 10% 且 ≤ 基準 + 2 個百分點。
選擇完成後不遞補候選；2024 或連續期間未通過就保留原策略。
